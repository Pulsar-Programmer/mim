Free for desktop. Always the latest release.

macOS

Your computer
  • Apple silicon .dmg
  • Intel .dmg

Open the disk image and drag MIM to Applications.

Windows

Your computer
  • Intel or AMD .exe
  • ARM .exe

If SmartScreen appears, choose More info, then Run anyway. Linking single files needs Developer Mode. Folders work without it.

Linux

Your computer
  • x86-64 AppImage
  • x86-64 .deb
  • ARM64 AppImage
  • ARM64 .deb

For an AppImage, run chmod +x MIM_*.AppImage first. For Debian or Ubuntu, run sudo apt install ./MIM_*.deb.

MIM updates itself from inside the app. Looking for an older version? See all releases on GitHub.
